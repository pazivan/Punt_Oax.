# PuntOax

### Plataforma web de localización de servicios de salud sexual y reproductiva en Oaxaca

**PuntOax** es un proyecto de desarrollo de software que tiene como objetivo facilitar el acceso a información confiable sobre centros de atención de salud sexual y reproductiva en el estado de Oaxaca, principalmente aquellos que ofrecen servicios de detección de Infecciones de Transmisión Sexual (ITS) e Interrupción Legal del Embarazo (ILE).

El proyecto surge ante la dificultad de encontrar información clara, actualizada y centralizada sobre estos servicios, ya que frecuentemente se encuentra dispersa entre páginas institucionales, redes sociales y diferentes medios de consulta.

## Objetivo del proyecto

Desarrollar una plataforma web interactiva, accesible y confidencial que permita a las personas localizar centros de atención mediante un mapa digital, consultar información verificada y encontrar servicios adecuados a sus necesidades.

## Funcionalidades principales

- **Mapa interactivo:** visualización geográfica de centros de atención en Oaxaca.
- **Directorio de centros:** consulta de establecimientos y servicios disponibles.
- **Búsqueda y filtros:** localización de centros según ubicación y tipo de servicio.
- **Información detallada:** acceso a direcciones, horarios, contactos y servicios ofrecidos.
- **Rutas de acceso:** redirección a Google Maps para obtener indicaciones hacia los establecimientos.
- **Privacidad:** consulta pública de información sin necesidad de registrarse.
- **Diseño adaptable:** acceso desde computadoras, tabletas y dispositivos móviles.

## Tecnologías del proyecto

La plataforma se desarrolla utilizando tecnologías web modernas:

- **Frontend:** React y Vite.
- **Backend:** Node.js y Express.
- **Base de datos:** PostgreSQL con extensión PostGIS.
- **Control de versiones:** Git y GitHub.
- **Gestión del proyecto:** metodología ágil Scrum.

## Impacto esperado

PuntOax busca reducir las barreras de acceso a la información sobre salud sexual y reproductiva, facilitando la identificación de servicios disponibles y promoviendo consultas informadas, accesibles y discretas.

La plataforma tiene un propósito exclusivamente informativo y de localización; no proporciona diagnósticos, consultas médicas ni atención sanitaria directa.
